# test_world 数据包（SpellMob 2.0.6+）

只给**指定名字**的生物挂施法规则，野生同类不受影响。

## 先让数据包真的生效

外部放进 `datapacks/` 的包，进世界时会被自动加载，但一旦 `/reload` 就可能被丢掉（日志里
`Loaded N spell caster definition(s)` 的 N 会掉回 6）。所以进游戏后先执行：

```
/datapack enable "file/test_world"
/reload
/spellmob resync
```

然后 `/spellmob info` 右键生物，能看到命中的变体名才说明规则加载成功。

## 召唤

```
/summon minecraft:husk ~ ~ ~ {CustomName:'"test-time"',CustomNameVisible:1b}
```

把名字换成下表里的任意一个即可，生物类型见第二列。

## 为什么之前看不到施法

1. 外部包的启用状态没有写进存档，`/reload` 之后只剩内置的 6 条定义（日志可见），规则等于没加载。
2. 之前的写法把 `priority` 写成 2，和僵尸自带近战目标（priority 2）同档，怪物会一直追人、轮不到施法。现在统一 `priority: 1`。
3. 之前的测试全是纯条件规则，白天/晴天本来就不该触发；现在每只都有一条无条件基础法术，先看到基础法术再谈条件。

## 注意

- 这个包会**覆盖内置的 `husk.json`**，启用期间内置双尸壳示例的规则会被替换。
- 僵尸、尸壳在白天会烧，需要白天的测试已经换成尸壳或烈焰人。
- 引导法术固定 `castTime: 80`（4 秒），冷却都不低于 60 tick（3 秒）。
